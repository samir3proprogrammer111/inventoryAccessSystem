# inventoryAccessSystem
Inventory Management System – Spring Boot + JWT + Role-Based Access
roject focuses on two roles:

USER → Can only view inventory
ADMIN → Can manage and update inventory

It demonstrates secure backend architecture using:

DTO Pattern
JWT Authentication
Spring Security
Role-Based Authorization
Admin/User Access Control
MySQL Database Integration
Features
ADMIN

Can:

View Inventory
Update Inventory
Manage Inventory Access
USER

Can:

Login
View Inventory Only

Cannot:

Update Inventory
Modify Inventory
Manage Inventory
Tech Stack
Java
Spring Boot
Spring Security
JWT (JSON Web Token)
Hibernate / JPA
MySQL
Maven
Lombok
REST APIs
